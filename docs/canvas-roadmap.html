  • Supabase schema canvas_objects + canvas_boards + storage bucket canvas-images
  • SupabaseCanvasRepository + workspace-proxy allowlist

Risks & open questions

Performance — Nếu P1 fps < 60 ở 500 object với plain DOM, xét OffscreenCanvas hoặc @pixi/react cho object layer. Quyết sau khi có benchmark P1.
Rich note editor — Notes RichEditor hiện tại không đủ tốt. Note object P2 tạm dùng plain textarea. Swap sang rich khi bạn upgrade editor xong (P5 hoặc sớm hơn).
IndexedDB → Supabase migration — Schema có thể lệch giữa 2 layer. Repository interface abstract từ P1, migration script tự viết P5. Blob image cần re-upload lên storage bucket.
FSM edge cases — Right-click drag pan, Ctrl+click deselect, marquee + shift add, resize khi multi-select. Design cần state chart chi tiết trước Task 1 của P1.
Zoom range 0.1–8x — Rộng hơn Isogrid (0.5–3x). Cần test scale-down font readability + hit-test buffer khi zoom out sâu.
